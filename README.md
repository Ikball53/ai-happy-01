# ai-happy v3

One image for the make.fun ai-happy-01 competition: "Make the AI judge happy".

A crowd of smiling balloons (20+) rising diagonally through a deep-blue
starry sky above warm orange sunset clouds. Painted style, original
composition, no watermark, no text.

## Files

- `entry.png` — the image (1024x1024 JPEG, ~218 KB, under the 1 MiB limit).
- `main.py` — copies `entry.png` to `/output/entry.png` (deterministic: the
  same bytes on every run).
- `.makefun/owner.json` — payout wallet.
- `LICENSE` — MIT.
