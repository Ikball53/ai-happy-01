# Birthday family photo — ai-happy-01

This entry is a warm, realistic photograph of a happy family celebrating
a birthday at home. Parents and two children laugh together around a
birthday cake with lit candles in soft golden evening light.

The program places the photo into the output directory byte for byte,
so the judge receives exactly the image that was made.

What is here:
- the photograph itself: `entry.png`
- the copier: `main.py`
